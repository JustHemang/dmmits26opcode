## 🌍 Project Overview

**Skill India Hub** is a digital career and skill-development platform designed to connect **students, young people, job seekers, and people from rural and village communities** with the right skills, training, internships, apprenticeships, and employment opportunities.

The idea is simple: bridge the gap between **talent and opportunity** — especially for people who don't have easy access to career guidance or information about what's available to them.

<div align="center">

### `DISCOVER` → `MATCH` → `LEARN` → `BUILD` → `PROVE` → `GET HIRED`

</div>

Instead of dumping a list of jobs or courses on users, the platform guides them:

> **Discovering their potential** → **Developing the right skills** → **Building their profile** → **Finding opportunities** → **Moving towards employment.**

<div align="center"><img src="https://capsule-render.vercel.app/api?type=waving&color=gradient&customColorList=6,11,20&height=60&section=header" width="100%"/></div>

## 🖥️ How It Works

Users land on the **Homepage**, explore what the platform offers, and once logged in, arrive at a personalized **Dashboard** — one place that brings together their career goals, skills, recommendations, and opportunities.

## 🚦 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev
```

Then open **[http://localhost:3000](http://localhost:3000)** in your browser. 🎉

## 📁 Project Structure

```text
src/
├── app/                 # App Router pages (dashboard, skilldna, jobs, radar, …)
├── components/
│   ├── home/            # Landing page sections
│   ├── layout/          # Navbar, footer, background, route guard, loader
│   ├── opportunities/   # Training / internship / job cards
│   └── ui/              # Reusable primitives (Button, Badge, Input, Icon, …)
└── lib/
    ├── ai/              # SkillDNA quiz + matching engine
    ├── data/            # Careers, categories, opportunities
    ├── db.ts            # localStorage persistence layer
    ├── auth.tsx         # Sign-in / sign-up + session management
    ├── i18n.tsx         # English / हिन्दी translations
    ├── store.tsx        # Global app state (saved, applications, roadmap, toasts)
    └── pdf.ts           # Resume PDF generation
```

## 💾 Data & Persistence

The app runs **local-first** — accounts, saved opportunities, applications, roadmaps, and progress all live in the browser's `localStorage`. No backend, no API keys, no setup friction. Accounts are created on-device and are immutable after signup.

> 🧪 **Try it:** hop into the **Employer Demo** from the "Hire & Get Hired" page to explore the employer workspace with sample jobs and applicants.
